# Real-Time Traction Control Architecture for a Differential Drive Rover

Embedded Control Project repository developed for the Master's Degree in **Automation and Robotics Engineering** at **Politecnico di Bari** (A.Y. 2025/2026).

## Project Overview
This project focuses on the design, simulation, and embedded implementation of a real-time traction control system tailored for an autonomous differential drive ground rover. The architecture aims to mitigate wheel slip, improve path-following stability under variable surface adhesion conditions, and meet hard real-time execution constraints.
